# Mohan Machinery Stores - Official Business Website

This repository contains the source code for the official website of **Mohan Machinery Stores**, a business based in Gwalior, Madhya Pradesh, specializing in commercial food processing equipment, industrial machinery, and agricultural motors.

##  Website Goals & Target Audience

### Goals
1. Establish a modern digital presence to showcase product inventory online.
2. Enable direct customer inquiries and leads via WhatsApp and interactive contact forms.
3. Provide business transparency with verified GST details, location maps, and operating hours.

### Target Audience
- Agricultural farmers, local flour mill operators, commercial food processors, and industrial buyers in Gwalior and surrounding regions of Madhya Pradesh.

---

##  Features & Architecture

- **Multi-Page Layout:** Clean navigation across `index.html`, `about.html`, `products.html`, and `contact.html`.
- **Product Catalog:** Showcases Flour Mills, Pulverizers, Electric Motors, Submersible Pumps, Dal Mills, and Machinery Spares.
- **Custom Branding & Theme:** Modern light-yellow background with bold crimson red accent elements.
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop screens using custom CSS flexbox and grid layouts.
- **Direct Lead Generation:** Integrated WhatsApp click-to-chat links and inquiry forms.

---

## Technology Stack

- **HTML5:** Semantic markup structure across all pages.
- **CSS3:** Custom styles (`style.css`), flexbox/grid layout systems, responsive media queries, and color variables.
- **GitHub Pages:** Static site hosting and continuous deployment.
